STEP 1: Configure MySQL
------------------------
Open MySQL and run:
  CREATE DATABASE smart_doc_verify CHARACTER SET utf8mb4;

STEP 2: Edit .env File
----------------------
Copy .env.example to .env:
  Copy-Item .env.example .env

Edit .env (notepad .env) and update:
  - SECRET_KEY: Generate with: python -c "import secrets; print(secrets.token_hex(32))"
  - DATABASE_URL: Add your MySQL password
  - ADMIN_PASSWORD: Choose your admin password
  - TESSERACT_CMD: Verify path is correct

STEP 3: Run Setup Script
-------------------------
  powershell -ExecutionPolicy Bypass -File setup.ps1

This will create database tables and seed data automatically.
